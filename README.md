# 🛡️ Life Warrior — Smart Emergency & Healthcare Assistance Platform

**Life Warrior** is a mobile-first emergency response and healthcare locator prototype designed to reduce critical time loss during medical emergencies. The platform instantly connects users to nearby medical facilities, displays real-time bed and operation theater availability, and provides direct access to on-call specialists.

## 🚀 Key Features

* **One-Tap SOS Zone:** Instantly triggers location tracking and emergency protocols.
* **Triage Status System:** Color-coded indicators (Green, Amber, Red) that show ICU and OT bed availability at a glance.
* **Smart Search & Filters:** Dynamic filtering for nearest locations, top-rated facilities, and immediate ICU availability.
* **Detail-Driven Modals:** Bottom-sheet interfaces providing access to verified doctor reviews, contact numbers, and direct map navigation.

## 🛠️ Built With

* **HTML5**
* **Tailwind CSS** (via CDN)
* **JavaScript (ES6)** — For dynamic filtering, sorting, and UI rendering.
* **Google Fonts & Icons** — Responsive, clean topography and scalable vector graphics.
